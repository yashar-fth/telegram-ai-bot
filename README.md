# ربات تلگرام هوش مصنوعی و خلاصه‌ساز کانال‌ها (Telegram AI Summarizer & Chatbot)

این پروژه یک ربات هوشمند تلگرام است که:
1. **کانال‌های عمومی تلگرام را رصد می‌کند**، پست‌های جدید را با مدل قدرتمند **Google Gemini** تحلیل و خلاصه می‌کند و به پیوی شما می‌فرستد.
2. **چت هوش مصنوعی:** مثل ChatGPT به هر پیام شما به زبان فارسی پاسخ می‌دهد.
3. **خلاصه پیام فوروارد شده:** هر پیامی را به ربات فوروارد کنید، نکات کلیدی و خلاصه‌اش را تحویل می‌دهد.
4. **اجرای خودکار و رایگان روی GitHub Actions:** بدون نیاز به روشن بودن کامپیوتر یا پرداخت هزینه سرور!

---

## 🚀 راهنمای سریع راه‌اندازی در گیت‌هاب (فقط در ۳ دقیقه)

### مرحله ۱: ساخت یک ریپازیتوری در گیت‌هاب
1. وارد سایت [GitHub.com](https://github.com) شوید.
2. از گوشه بالا راست روی دکمه **+** و سپس **New repository** کلیک کنید.
3. نام ریپازیتوری را دلخواه وارد کنید (مثلاً `telegram-ai-bot`) و حالت آن را روی **Public** یا **Private** بگذارید.
4. دکمه **Create repository** را بزنید.

### مرحله ۲: آپلود این فایل‌ها به گیت‌هاب
فایل‌های این پوشه شامل موارد زیر هستند:
- `bot.py`
- `seen_posts.json`
- `requirements.txt`
- پوشه `.github/workflows/` (حاوی `channel_monitor.yml` و `live_bot.yml`)

می‌توانید به سادگی با کلیک روی **Upload an existing file** در صفحه گیت‌هاب، این فایل‌ها را Drag & Drop کنید و دکمه **Commit changes** را بزنید.

### مرحله ۳: وارد کردن کلیدها در GitHub Secrets (امنیت بالا)
برای اینکه توکن‌ها و کلیدهای شما امن بمانند:
1. داخل صفحه ریپازیتوری گیت‌هاب، به تب **Settings** بروید.
2. از منوی سمت چپ، روی **Secrets and variables** و سپس **Actions** کلیک کنید.
3. دکمه سبز رنگ **New repository secret** را بزنید و این ۳ مورد را اضافه کنید:

| نام سکرت (Name) | مقدار (Value) |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات دریافتی از BotFather |
| `TELEGRAM_CHAT_ID` | شناسه عددی چت شما |
| `GEMINI_API_KEY` | کلید هوش مصنوعی جمینای |

### مرحله ۴: فعال‌سازی مجوزهای گیت‌هاب (Workflow Permissions)
برای اینکه گیت‌هاب بتواند آخرین پست‌های بررسی‌شده را ذخیره کند:
1. در همان بخش **Settings**، روی منوی **Actions** > **General** کلیک کنید.
2. صفحه را اسکرول کنید تا به بخش **Workflow permissions** برسید.
3. گزینه **Read and write permissions** را انتخاب کنید و دکمه **Save** را بزنید.

---

## ⚡️ تست فوری
1. به تب **Actions** در بالای صفحه ریپازیتوری گیت‌هاب بروید.
2. از ستون سمت چپ روی **Telegram Channel AI Summarizer** کلیک کنید.
3. دکمه **Run workflow** را بزنید!
4. پس از چند ثانیه، خلاصه پست‌های کانال به تلگرام شما ارسال خواهد شد! 🚀
